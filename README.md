# PELCON FARM AI 🐑

Web εφαρμογή Python/Streamlit για δοκιμαστική ανίχνευση και καταμέτρηση προβάτων σε φωτογραφίες και βίντεο.

## Εκκίνηση τοπικά

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Δημοσίευση

Streamlit Community Cloud: επιλέξτε το repository, branch `main` και main file `app.py`.

## Σημαντικοί περιορισμοί

- Χρησιμοποιεί γενικό μοντέλο YOLO (COCO class sheep). Η ακρίβεια σε πυκνά κοπάδια χρειάζεται επιβεβαίωση.
- Η καταμέτρηση φωτογραφίας αφορά ορατές ανιχνεύσεις, όχι κρυμμένα ζώα.
- Το βίντεο εμφανίζει καταμέτρηση ανά επιλεγμένο καρέ, **όχι** μοναδικό πλήθος ζώων.
- Δεν αναγνωρίζει μόνιμη ταυτότητα ή RFID ζώου.
- Το Streamlit Community Cloud έχει όρια πόρων και ενδέχεται να αδρανοποιείται.

Μην ανεβάζετε προσωπικά δεδομένα ή μυστικούς κωδικούς στο repository.
